# Enhanced Security Branch

This branch contains the enhanced encrypted private configuration security feature as requested by @bulton-fr.

## Key Features

- AES-256-GCM encryption for private configuration files
- Module-specific key derivation
- Automatic detection of encrypted files
- Backward compatibility with plain files
- Comprehensive testing and documentation

See the main documentation in `docs/en/how-it-works/create-module.md` for full details.
